## 未执行及实际限制

- 未连接设备、烧录或实际写Flash；未验证模拟电路、模块电源时序、晶振、中断延迟、UART误码、Flash掉电和功耗。
- Keil FVP测试镜像已编译，但独立FVP因缺失FM_Simulator/FVP_ARM_Cortex-M0PLUS许可证无法运行；没有声称FVP通过。已改用Unicorn执行同一镜像和板级替身，不绕过FVP授权。
- 未执行硬件看门狗、升级或Flash定位缓存测试，因为这些功能没有引入。HardFault复位后的重复故障策略仍需产品验收。
- UART0在115200下511字节有效容量约44ms；网络/HTTP轮询期间前台应保持及时运行。采样有界同步步骤只在没有在途AT时调用；串口连续噪声和真实URC峰值仍需实测。
- 温度单位、QNTP时区后缀、HTTPREAD终结形式需对真实模块/服务器核对。所有这些仍未被模型替身证明。

## 交付后的实板验收顺序

1. 核对引脚、模块型号及协议版本，先记录原始UART流，不发送到未知设备。
2. 验证SN提交断电、自检拒绝/批准和激活三按；检查历史身份组合迁移。
3. 验证两种定位与网络故障，首次及后续上传失败、缓存满和补传。
4. ADC永不完成、I2C卡死、UART超长与噪声注入，确认均能返回或进入有界关机。
5. RTC/按键提前唤醒、跨午夜和时钟同步；测量栈水位、工作电流及深睡电流。
