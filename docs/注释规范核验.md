# 注释规范核验（main基线历史记录）

本文件“代码未改/HEX一致”仅指d54f2f1基线的补注释过程。EG800Z-EU适配有意修改行为，请使用[当前分支验证记录](EG800ZEU_验证记录.md)。

本次针对上一版实现注释不足的问题，按上层与本工程 AGENTS.md 补齐注释。仅修改自有源码的注释与格式、工程约定和交付说明；没有重构执行逻辑。原工程、vendor 与 baseline 保持原样。

## 逐类核验

| 对象 | 本次落实内容 |
|---|---|
| 文件/模块 | 32个自有C/H注明职责、依赖、边界及前台/IRQ执行上下文；启动汇编注明栈、堆及向量适配边界 |
| 函数 | 158个自有C函数定义均有中文用途说明，包含板级替身与测试函数；公开完整契约集中在头文件，私有复杂函数补充条件和失败行为 |
| 公开接口 | 85个头文件函数契约逐项核对；有参接口的所有参数均有同名标签，说明输入/输出、单位、容量、有效条件、生命周期或NULL行为 |
| 值对象/状态 | 业务类型、状态枚举、错误码、重要字段注明含义；区分在途、接受、完成与业务批准，不把启动成功当作任务完成 |
| 资源/并发 | UART环、共享时基与事件的读写者和临界区责任；AT单实例、步骤拥有者、只读借用期限、FIFO有效项和满覆盖行为 |
| 常量/硬件 | 配置默认值、单位及修改影响；引脚来源、未核实极性/电路条件；不伪造数据手册依据或实测结果 |
| 复杂实现 | 取消与关机顺序、状态进入退出、配置整组提交、缓存成功后出队、超时排空、I2C恢复、ADC清理、Welford方差、睡眠竞态和时基余数 |
| 工具/测试 | 构建/测试/格式/依赖准备脚本说明用途、边界和输出；测试说明模拟前提，不把模型运行写成实板验收 |

人工检查特别纠正了旧注释中的误导：定位启动参数的实际内容、取消采样仍可能保留旧快照、PB4供电与PA4控制的区别、时间戳生成时刻，以及未传播的DDL返回值。公开契约以实际实现为依据，不将期望行为当作已经实现。

## 核验结果

- 32个C/H的注释外代码token逐文件与本轮修改前完全一致；3个自有汇编文件去掉注释/空白后的有效行一致。
- 158个函数用途检查、32个模块契约检查、85个公开接口参数标签检查均无缺项。详细路径、函数行号、修改前后SHA-256及检查结果见[注释规范核验.json](注释规范核验.json)。这是结构覆盖证据，不能代替注释语义审阅或硬件验证。
- 自有C/H格式检查通过；ARMCC独立构建通过；MDK构建0错误、2个既有厂商ADC枚举告警。
- ARM指令模型回归：123项检查，0失败。
- 独立构建与MDK各自的HEX均与本轮修改前逐字节一致。二者使用不同链接排列，比较的是各自前后版本，未声称两种构建的HEX互相一致。

## 实际边界

第三方/生成代码和原始baseline不批量改写。硬件时序、温度标度、模块协议版本、Flash掉电行为与真实功耗尚未实板验证；相关未知条件在接口与实现中如实标注。此次没有修改这些实现，没有烧录设备。后续修改仍须遵循本工程AGENTS.md中的注释核验约定。
